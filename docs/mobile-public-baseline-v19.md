# V19 — Mobile Public Baseline

Final public-beta cleanup:

- CCTV road/segment groups no longer auto-open the first result; all groups start compact and open only on user request.
- Official CCTV cache now preserves its published update timestamp so the UI can show camera-list freshness.
- Charging city selector is 44px minimum height.
- Charging favorite control is enlarged to 40px.
- Charging result-clear control is at least 36px.
- CCTV group summary is at least 44px.

V19 intentionally adds no new feature. It is the mobile/public-testing baseline after V18.
